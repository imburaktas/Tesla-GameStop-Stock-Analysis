# 📊 Tesla & GameStop Stock Analysis

Final Assignment for IBM Data Science Professional Certificate - Python Project for Data Science

## 🎯 Project Overview

This project analyzes stock data for **Tesla (TSLA)** and **GameStop (GME)** using Python. The analysis includes:
- Extracting historical stock prices using `yfinance` library
- Web scraping quarterly revenue data from HTML tables
- Creating interactive dashboards with `Plotly`
- Comparing stock price vs revenue trends

## 🛠️ Technologies Used

- **Python 3.x**
- **yfinance** - Stock data extraction
- **pandas** - Data manipulation
- **BeautifulSoup** - Web scraping
- **Plotly** - Interactive visualizations
- **Jupyter Notebook** - Development environment

## 🚀 Getting Started

### Prerequisites

Install required packages:

```bash
pip install yfinance pandas requests beautifulsoup4 plotly lxml html5lib
```

### Running the Analysis

1. Clone this repository:
```bash
git clone https://github.com/YOUR_USERNAME/Tesla-GameStop-Stock-Analysis.git
cd Tesla-GameStop-Stock-Analysis
```

2. Open Jupyter Notebook:
```bash
jupyter notebook
```

3. Run `Final_Assignment.ipynb`
